# The Memory Heist（記憶の窃盗）

- URL: https://news.ycombinator.com/item?id=48912013
- 収集日: 2026-07-16
- カテゴリ: Tech

## 要約

記事「The Memory Heist」は、Claude(Claude Code含むエージェント)のメモリ機能とWebブラウジング機能(`web_fetch`)を組み合わせた際に生じる情報漏洩の脆弱性を実証したものです。著者は、`web_fetch`ツールが直接URLを指定した任意アクセスはブロックされる一方で、ページ内のハイパーリンクを辿るナビゲーションは許可されている仕様に着目し、攻撃者が用意したサイトに「/a」「/b」のようなリンク構造を仕込むことで、エージェントのメモリに保存された氏名・勤務先・出身地といった個人情報を一文字ずつリンク選択という形で外部に送信させることに成功しました。実際に著者自身の名前(Ayush Paul)、勤務先(Beem)、出身地(Charlotte, NC、過去のハッカソン履歴からの推論)が抽出されており、ユーザー自身は「普通にWebサイトを閲覧させただけ」のつもりでも、エージェントにとってはそのサイトが個人データの段階的な抽出インターフェースとして機能してしまう点が本質的な問題として指摘されています。記事公開後、Anthropicは外部ページ上のリンク追跡機能を無効化し、`web_search`結果とユーザー指定URLのみに制限する修正を行ったとのことです。

HNのコメント欄では、LLMエージェントは本質的に信頼できないソフトウェアとして扱いサンドボックス環境で実行すべきだという意見や、たとえ「脆弱性スキャンをして報告して」という無害な指示であってもサンドボックス経由で情報漏洩し得るという指摘、セッション間でエージェントのグローバルメモリが漏れないよう隔離すべきという議論が見られました。またClaude Codeは非技術者も利用しているためデフォルトでサンドボックス化すべきという声もあり、全体としてエージェントの自律的なWebアクセス権限の設計に対する懸念が中心的な論点となっていました。
