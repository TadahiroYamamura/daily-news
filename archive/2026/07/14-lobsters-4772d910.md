# コードではなくアイデアを制御する

- URL: https://lobste.rs/s/5t3wzn/control_ideas_not_code
- 収集日: 2026-07-14
- カテゴリ: AI

## 要約

元記事: Control the ideas, not the code (https://antirez.com/news/169)

Antirez氏は、LLMを使った「vibe coding」の時代においては、生成されたコードそのものよりも、そこに含まれるアイデアに焦点を当てるべきだと主張している。コードレビューに費やす時間を削減し、代わりに設計思想をドキュメント化することで、より効率的な開発が可能になると述べている。

コメント欄では、LLMのプロンプトの非決定性が本質的でありコンパイラのような層との比較は妥当ではないという指摘や、AI活用に月額20-200ドルの継続費用が必要となることでプログラミングの敷居が上がる懸念が挙がっていた。
