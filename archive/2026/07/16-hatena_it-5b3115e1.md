# ニチレイ サイバー攻撃を公表 外食企業や食品メーカーに影響

- URL: https://news.web.nhk/newsweb/na/na-k10015177751000
- 収集日: 2026-07-16
- カテゴリ: Security

## 要約

冷凍食品大手のニチレイは、7月13日午前6時50分ごろにグループ内で不正アクセスによるシステム障害を検知し、調査の結果、自社サーバーへのサイバー攻撃を確認したとして15日に公表した。影響を受けているのはニチレイロジグループ各社が担う冷蔵倉庫の入出庫業務と、ニチレイフーズによる冷凍食品の出荷業務で、個人情報流出の可能性も指摘されている。

この物流障害は取引先の外食・小売各社にも波及した。食材配送をニチレイロジグループに委託している日本ケンタッキー・フライド・チキンは14日、7月14日以降に一部店舗で商品の品切れやメニュー制限、営業時間短縮、在庫状況によっては臨時休業が生じる可能性があると発表し、公式アプリ・ウェブサイトからの注文、デリバリー、配達代行、クーポン・モバイルオーダーも一時停止した。イオンでも冷凍食品を中心に欠品が発生し、回転ずしチェーンのくら寿司でも寿司ネタなどの配送遅延・未着が確認されている。ニチレイは17日からの業務再開を見込んでいると報じられている。
