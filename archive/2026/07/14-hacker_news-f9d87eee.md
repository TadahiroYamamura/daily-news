# Show HN: Jacquard――AIが書きレビューする前提のプログラミング言語

- URL: https://news.ycombinator.com/item?id=48894630
- 収集日: 2026-07-14
- カテゴリ: AI

## 要約

元記事: Show HN: Jacquard, a programming language for AI-written, human-reviewed code (https://github.com/jbwinters/jacquard-lang)

AI生成コード向けに設計されたプログラミング言語Jacquardが発表された。関数署名に外部効果(ファイルシステム、ネットワークアクセスなど)を明示し、実行時に明示的な許可を要求する仕組みを持つ。Warpというテストフレームワークを備え、コンテンツアドレッシングによりコードの整形やリネーム時の再コンパイルが不要になる。AIエージェントが利用しやすいよう設計されている。

コメント欄では、多重ショット効果の複雑さが人間にとって理解しにくいという懸念や、既存言語(Python/JS等)の膨大なトレーニングデータに対して新言語が不利という懐疑的な意見が見られた。
