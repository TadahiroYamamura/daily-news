# Microsoft、過去最多570件のセキュリティ脆弱性を修正

- URL: https://news.ycombinator.com/item?id=48913190
- 収集日: 2026-07-15
- カテゴリ: Security

## 要約

元記事: Microsoft Patches a Record 570 Security Flaws (https://krebsonsecurity.com/2026/07/microsoft-patches-a-record-570-security-flaws/)

Microsoftは2026年7月の月例パッチで570件のセキュリティ脆弱性を修正し、前月の約3倍という過去最多の件数となった。うち約60件は「緊急(critical)」評価で、攻撃者がユーザー操作をほとんど必要とせずにWindows端末を遠隔操作できるもの。すでに3件のゼロデイ脆弱性が実際に悪用されていたことも判明している。注目すべき脆弱性として、Active Directory Federation Servicesの権限昇格(CVE-2026-56155)、SharePointの権限昇格(CVE-2026-56164)、物理アクセス経由でBitLocker暗号化データにアクセス可能なバイパス(CVE-2026-50661)、CVSS 9.6のMicrosoft Copilotリモートコード実行(CVE-2026-48561)などが挙げられており、全体では権限昇格系のバグが約250件を占めた。

Microsoft幹部のPavan Davuluri氏は、この急増の背景としてAIによる脆弱性発見支援の進歩を挙げ、「AIの進歩により、より多くの問題をより速く、より広範なコードにわたって発見できるようになった」と説明した。一方でセキュリティ専門家は、AIは脆弱性の発見だけでなくエクスプロイト開発も加速させるため、人間の能力を前提に設計されてきたMicrosoftの悪用可能性指標(exploitability index)自体が時代遅れになりつつあると警鐘を鳴らしている。Adobe、Cisco、Mozilla、Oracleなども同様にパッチ頻度を増やしており、Googleは2026年6月に900件超の修正をリリースするなど、業界全体で脆弱性開示・修正の規模が拡大している。

Hacker Newsのコメント欄では、AIによるバグ発見を歓迎する声がある一方、人間の知見による発見の質の高さを支持する意見や、大量の修正が新たなバグを生む懸念、Chromium系ブラウザの428件の脆弱性と比較して急速な開発手法自体を見直すべきという指摘も出ている。また、ユーザーが求めていない機能追加を優先する開発姿勢や、パッチ配布の一元化メカニズムの欠如を問題視する声、20年前の複雑なソフトウェアにも同程度の潜在的脆弱性があった可能性を指摘する意見もあり、脆弱性件数の急増をどう解釈すべきかについて多様な視点が交わされている。
