# 依存関係ファイアウォールとは何か

- URL: https://www.aikido.dev/blog/what-is-a-dependency-firewall
- 収集日: 2026-07-15
- カテゴリ: Security

## 要約

依存関係ファイアウォールとは、悪意あるオープンソースパッケージがインストールされる前にブロックするチェックポイントのことである。ネットワークファイアウォールがパケットを検査するのと同様に、`npm install`のようなパッケージインストール操作を検査対象とする点が特徴だ。背景には攻撃の急増があり、Aikido Intelは1日最大10万個の悪意あるパッケージを分析しており、これは1年前の2万個から大幅に増加している。インストール時点でのブロックが重要な理由として、パッケージは`postinstall`フックなどにより開発者の権限で即座にコードを実行できること、AIコーディングエージェントやMCPサーバーが人間の監視なしに自動でパッケージをインストールするようになったこと、悪意あるパッケージは24時間以内に削除されることが多くインストール後の検出では対応が遅すぎること、axios・chalk・debugなど数百万週間ダウンロードを誇る信頼済みライブラリでもメンテナーアカウント侵害により悪意あるバージョンが配布され得ることが挙げられている。

依存関係ファイアウォールが検査する項目としては、既知マルウェアとの照合、公開後24〜48時間以内など「新しすぎる」パッケージの遮断、`lodahs`のような正規パッケージ名を模倣するタイポスクワッティングの検出、内部パッケージ名を公開レジストリで乗っ取る依存関係混乱の防止、インストールスクリプトの接続先・挙動の検査、メンテナー変更や不可解な依存関係追加などアカウント侵害の兆候の検知、見えないUnicode文字や隠れたペイロードなどの難読化技術の発見が挙げられる。

Aikidoは自社のソリューションとして、npm・yarn・pnpm・pipに対応するオープンソース(MIT License)の無料実装「Safe Chain」、MDM統合により組織全体へ導入できる「Aikido Device Protection」、20以上のエコシステムをリアルタイム分析する公開脅威フィード「Aikido Intel」(AGPL)を提供している。
