# 多層防御 vs 最先端のサプライチェーン攻撃 ―― freee の大規模障害訓練の舞台裏

- URL: https://developers.freee.co.jp/entry/redteam-exercise-2026
- 収集日: 2026-07-16
- カテゴリ: Security

## 要約

OSSサプライチェーン攻撃の激化を受け、freeeの赤チームはエンジニア組織にスコープを絞ったレッドチーム演習を2026年7月15日に実施しました。SRE・セキュリティ専門家・被害者役の開発者・カスタマーサポートなど12名体制で、OSSパッケージに混入したマルウェアで開発者端末が侵害され、Package Registry経由でGitHub・CI/CD・AWS環境へと侵入が拡大するというサプライチェーン攻撃シナリオをLLMも活用しつつ構築し、現実味のある組織固有の脅威として設計しました。

防御側にはSSO+MFA強制、シークレットスキャン、ブランチ保護と第三者レビュー、SIEMによるログ監視、AWS Network Firewallといった多層防御が既に存在しており、実際にメインシナリオの侵害発生からわずか5分で異常なフローの検知には成功しました。一方で根本原因の特定までは至らず、SIEMと連携するAIエージェントが削除済みログを延々と探索し続けてしまう挙動が判明するなど、ログ調査の並列化やプロンプト設計の改善といった具体的な課題が浮き彫りになりました。

演習にはエンジニア以外のメンバーも自発的に加わり、ユーザー対応や関係部署への連絡といった実運用に近い動きも再現された点が特徴です。訓練後には攻撃経路を根本から排除するためのプロジェクトが立ち上がり、GitHubのセキュリティ強化やトークン管理の改善へとつながるなど、演習で得た知見が実際の組織的な改善アクションに反映されています。
